# Dynatrace OSS Homebrew Tap

Homebrew formulae for Dynatrace open-source tools.

## Available Formulae

| Formula | Description |
|---------|-------------|
| [dtctl](https://github.com/dynatrace-oss/dtctl) | kubectl-inspired CLI for Dynatrace |
| [dtmgd](https://github.com/dynatrace-oss/dtmgd) | kubectl-inspired CLI for Dynatrace Managed |
| [dtui](https://github.com/dynatrace-oss/dtui) | Interactive, keyboard-driven terminal UI for Dynatrace |

## Installation

```bash
brew install dynatrace-oss/tap/dtctl
brew install dynatrace-oss/tap/dtmgd
brew install dynatrace-oss/tap/dtui
```

## Updating

```bash
brew update
brew upgrade dtctl
brew upgrade dtmgd
brew upgrade dtui
```
